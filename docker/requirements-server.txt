# / numpy / pandas / psutil / pyyaml / pillow ...) comes from requirements-cpu.txt,

# requires ultralytics (engine.py imports ultralytics.YOLO at module level, and

# the tested CPU stack verbatim plus this web layer. See docker/Dockerfile.server.
